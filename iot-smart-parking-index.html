Smart Parking Door System
Using IoT

Arduino Uno

Main controller. Reads the IR sensor and controls the servo motor according to the detected vehicle condition.

Detects the presence of a vehicle near the gate and provides the input signal to the Arduino.

How the system works

The control process is automatic: sensor input → Arduino decision → servo movement.

1. Detection: The IR sensor monitors the entrance area.
2. Input: When a vehicle is detected, the sensor state is read by the Arduino.
3. Processing: Arduino applies the programmed gate-control logic.
4. Opening: The servo rotates the barrier to allow vehicle movement.
5. Closing: After the programmed condition, the servo returns the barrier toward its closed position.

Conclusion

Academic project summary.

The Smart Parking Door System demonstrates a compact automated gate using Arduino Uno + IR Sensor + Servo Motor. The system detects a vehicle, processes the sensor input and controls the barrier automatically. Its low component count, simple control logic and low prototype cost make it suitable for demonstrating IoT and embedded automation concepts.
