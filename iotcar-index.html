The supplied source report describes a WiFi-based robotic car in which the ESP8266 acts as both controller and web server.

Pin map from the supplied report

D1/D2 → left motor direction; D3/D4 → right motor direction; D0/D5 → speed enable; D6/D7/D8 → indicators; the supplied appendix also assigns D6 to the horn.

Working sequence

A simple real-time control chain.

01 — Power ON: battery powers the motor-control system and NodeMCU starts.
02 — WiFi: NodeMCU creates the local WiFi network and starts the web server.
03 — Connect: smartphone connects to the car network and opens the control page.
04 — Command: browser sends short commands such as F, B, L, R, S and H.
05 — Processing: ESP8266 routes the command to the appropriate function.
06 — Output: L298N drives the motors while indicators/horn respond as programmed.

Conclusion

A concise project-level conclusion.

The IoT Based WiFi Controlled Car demonstrates how an ESP8266 can combine wireless networking, web-server control and embedded motor control in a compact robotic vehicle. The documented system integrates directional movement, PWM speed control, indicators and a horn, providing a practical demonstration of IoT, embedded systems and robotics.
