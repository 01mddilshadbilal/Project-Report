Project Overview

Expense Manager is designed to help users record, organize and understand personal financial activity from a single Android application.

Problem Statement

Personal financial records can become scattered across notes, messages and memory. The project addresses this by bringing transactions, balances, reports, calendar views and personal ledgers into one mobile interface.

Project Objective

To build a practical, visually organized Android solution for recording income and expenses, reviewing financial history, handling person-wise Udhar records, and protecting private financial information.

Core Features

The feature set below is based on the supplied Android project structure, activities, layouts and implementation classes.

💰 Transactions & Balance

Add income and expense transactions, maintain stored records, calculate balance, and distinguish cash and online amounts.

📊 Financial Analysis

Monthly report and transaction history screens provide structured views for reviewing financial activity.

📅 Calendar View

Calendar-based navigation helps users associate financial activity with dates.

🤝 Personal Ledger / Udhar

Person-wise ledger records support amounts given and received, descriptions, history and balance status.

🔐 Security

Authentication flows, app lock and biometric-related dependencies are included in the project.

🎨 Themes & Settings

Theme management and settings screens provide personalization and configuration controls.

🗑️ Recycle Bin

Deleted transaction data is handled through a dedicated recycle-bin module rather than immediately disappearing from the interface.

🔔 Reminders

The project includes reminder scheduling and a reminder receiver for notification-related functionality.

System Architecture

The implementation uses a traditional Android activity-based UI with local data management, Firebase services for authentication/cloud-related functionality, and supporting utility/security classes.

Presentation Layer

Activities + XML layouts + ViewBinding + RecyclerView adapters

Application Logic

Transaction, report, theme, reminder, authentication and ledger activities/classes

Data Layer

SQLite via DatabaseHelper, SharedPreferences and Firebase services

Application Flow

Splash→Authentication / Lock→Dashboard→Transactions→Reports / Calendar→Ledger / Settings

Technology Stack

  • Android / Java
  • XML-based UI with ViewBinding
  • SQLite database through SQLiteOpenHelper
  • Firebase Authentication and Firestore dependencies
  • AndroidX Material, RecyclerView, ConstraintLayout and Biometric APIs
  • Compile SDK 36, minimum SDK 21, Java 11 compatibility

MonthlyReportActivity.java
package com.example.expensemate;

import android.os.Bundle;
import android.widget.TextView;
import androidx.appcompat.app.AppCompatActivity;
import java.util.Locale;

public class MonthlyReportActivity extends AppCompatActivity {

    private TextView monthIncome, monthExpense, monthBalance;
    private DatabaseHelper dbHelper;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_monthly_report);

        monthIncome  = findViewById(R.id.monthIncome);
        monthExpense = findViewById(R.id.monthExpense);
        monthBalance = findViewById(R.id.monthBalance);

        dbHelper = new DatabaseHelper(this);

        loadReport();
    }

    private void loadReport() {
        double income  = dbHelper.getTotalIncome();
        double expense = dbHelper.getTotalExpense();
        double balance = income - expense;

        monthIncome.setText(String.format(Locale.getDefault(),  "₹%.2f", income));
        monthExpense.setText(String.format(Locale.getDefault(), "₹%.2f", expense));
        monthBalance.setText(String.format(Locale.getDefault(), "₹%.2f", balance));
    }
}
